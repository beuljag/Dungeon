# Dungeon

입장할 때마다 맵이 달라지는 층별 보스 던전 Paper 1.21.1 플러그인입니다.

- 직접 지은 방을 입장할 때마다 랜덤으로 회전하고 연결해 맵을 조립
- 파티마다 자기만의 던전이 따로 생성 (솔로도 가능)
- 층 보스를 잡아야만 아래층으로 내려가거나 나갈 수 있음
- 던전에서 죽으면 아이템을 모두 잃음 (귀속 저주가 붙은 아이템은 유지)
- 층마다 나오는 몹, 보스, 보상을 직접 지정 (기본 몹, MythicMobs 모두 가능)

> **테스트 상태:** 복사본 서버에서 봇 2개로 방 저장, 맵 조립과 회전, 파티 입장, 몹과 보스 소환, 사망과 관전, 보상 상자, 층 이동, 재접속, 시간 초과, 클리어, 서버 정상 종료와 강제 종료 복구까지 확인했습니다. 사람이 직접 접속한 플레이, **MythicMobs 몹과 보스**, Citizens 같은 NPC 플러그인 연결, 직접 지은 복잡한 방, 여러 파티 동시 진행, 운영 서버 설치는 아직 시험하지 않았습니다.

## 설치

1. `Dungeon-Plugin.jar`를 서버의 `plugins` 폴더에 넣습니다.
2. 서버를 재시작합니다.

**WorldEdit이 꼭 필요합니다.** MythicMobs는 미믹몹을 쓸 때만 필요합니다.

> 던전 전용 월드 `dungeon_instances`는 **서버를 켤 때마다 지우고 새로 만듭니다.** 이 이름의 폴더에 다른 것을 두지 마세요. 이름은 `config.yml`의 `world-name`에서 바꿀 수 있습니다.

## 빠른 시작

### 1. 방 짓기

방은 시작 방, 일반 방, 보스 방 세 종류이고 각각 하나 이상 필요합니다. 아무 월드에 방을 지은 뒤 **표지판으로 위치를 표시**합니다. 표지판의 첫 줄(앞면)만 읽으며, 던전에서는 표지판이 지워집니다.

| 첫 줄 | 의미 | 필요한 방 |
|---|---|---|
| `[문]` | 다른 방과 연결되는 문의 바닥 가운데 칸 | 모든 방 (1개 이상) |
| `[시작]` | 플레이어가 나타나는 곳 | 시작 방 |
| `[몹]` | 일반 몹이 나오는 곳. 표지판 1개에 1마리 | 선택 |
| `[보스]` | 보스가 나오는 곳 | 보스 방 |
| `[보상]` | 보스를 잡으면 상자가 생기는 곳 | 보스 방 |
| `[다음층]` | 다음 층 발판 | 보스 방 |
| `[나가기]` | 출구 발판 | 보스 방 |

**문 규칙**

- 저장할 영역의 **바깥 벽면**에 두어야 합니다. 모서리에 닿으면 안 됩니다.
- 기본 크기는 너비 3, 높이 3입니다. 다른 크기는 둘째 줄에 `5x4`처럼 `너비x높이`로 적습니다. 너비는 홀수만 됩니다.
- 벽에 문 크기만큼 구멍을 뚫어 두세요. 크기가 같은 문끼리만 연결되고, 연결되지 않은 문은 자동으로 막힙니다.
- 일반 방에는 문이 **2개 이상** 있어야 다음 방으로 이어질 수 있습니다.

### 2. 방 저장

WorldEdit으로 방 전체를 선택하고 저장합니다.

```
//pos1
//pos2
/던전 방 저장 <이름> <시작|일반|보스> [테마]
```

표시가 빠졌거나 문 위치가 잘못되면 이유를 알려 주고 저장하지 않습니다. 저장한 방은 `plugins/Dungeon/rooms/`에 들어갑니다.

### 3. 던전 만들기

```
/던전 생성 유적
/던전 층수 유적 3
/던전 방수 유적 1 5
/던전 보스 유적 1 mythic:SkeletonKing
/던전 몹 유적 1 추가 ZOMBIE 3
/던전 몹 유적 1 추가 mythic:Goblin 1
/던전 보상 유적 1 추가 50
/던전 정보 유적
```

- `방수`는 시작 방과 보스 방을 뺀 일반 방의 수입니다.
- 몹 뒤의 숫자는 가중치입니다. 위 예시면 `[몹]` 표지판마다 좀비가 3/4, 고블린이 1/4 확률로 나옵니다.
- `보상 추가`는 **손에 든 아이템**을 그 확률(%)로 등록합니다. 이름이나 인챈트가 붙은 아이템도 그대로 저장됩니다.
- `정보`에 `입장 가능`이 나오면 준비가 끝난 것입니다. 부족한 것이 있으면 그 내용이 대신 나옵니다.

### 4. NPC에 연결

콘솔 권한으로 아래 명령어를 실행하게 하면 어떤 NPC 플러그인이든 연결할 수 있습니다.

```
/던전 입장 <던전> <플레이어>
```

Citizens 예시입니다.

```
/npc command add dungeon enter 유적 <p>
```

NPC로만 들어오게 하려면 `config.yml`에서 `allow-player-enter-command: false`로 설정합니다.

## 던전 규칙

### 입장과 진행

- 파티가 있으면 파티장이 입장해야 하고, 접속 중인 파티원이 함께 들어갑니다.
- 맵이 준비되면 5초 뒤 입장합니다. 빠지려면 그 사이에 `/던전 파티 나가기`를 입력합니다.
- 입장하면 서바이벌 모드가 되고, 나올 때 원래 게임 모드와 원래 자리로 돌아갑니다.
- 일반 몹과 보스는 플레이어가 그 방에 처음 들어갈 때 나옵니다. 몹은 리젠되지 않습니다.
- 일반 몹을 다 잡지 않아도 보스 방에 갈 수 있습니다.

### 보스를 잡으면

- 보상 상자와 `나가기` 발판, `다음 층` 발판이 생깁니다. 마지막 층에는 다음 층 발판이 없습니다.
- `나가기`를 밟으면 그 사람만 아이템을 가지고 나갑니다.
- 누군가 `다음 층`을 밟으면 10초 뒤 남은 파티원이 모두 내려갑니다. 그 사이에 나가기를 밟으면 빠질 수 있습니다.
- 상자는 각자 따로 열립니다. 보스가 죽을 때 살아 있던 사람만 받을 수 있고, **층을 떠나면 꺼내지 않은 보상은 사라집니다.**

### 죽었을 때

- 인벤토리와 갑옷, 왼손의 아이템 중 **귀속 저주가 없는 것은 모두 삭제**됩니다. 바닥에 떨어지지 않습니다.
- 레벨과 경험치, 엔더 상자의 아이템은 유지됩니다.
- 귀속 저주는 아이템 자체에 붙어 있어야 합니다. 귀속 저주 인챈트북이나 귀속 저주 아이템이 든 셜커 상자는 보호되지 않습니다.
- 죽은 사람은 관전 모드로 남아 다음 층까지 따라다니고, 보상은 받지 못합니다.
- 전원이 죽으면 던전이 끝나고 모두 원래 자리로 돌아갑니다.

### 접속이 끊겼을 때

- 5분 안에 돌아오면 이어서 합니다. 그 사이 파티가 내려갔으면 현재 층의 시작 지점으로 갑니다.
- 5분을 넘기면 사망 처리되어, 다음 접속 때 아이템을 잃고 원래 자리로 돌아갑니다.
- 서버가 재시작되거나 꺼지면 **아이템을 잃지 않고** 원래 자리로 돌아갑니다. 진행 중이던 던전은 사라집니다.
- 서버가 크래시로 죽으면 다음 접속 때 원래 자리로 돌아갑니다. 인벤토리는 마인크래프트 기본 동작대로 마지막 저장 시점으로 되돌아갑니다.
- 접속이 끊긴 채 복귀 시간을 넘긴 뒤에 서버가 꺼져도 사망 처리는 그대로 유지됩니다.

### 던전 안에서 막히는 것

- `allowed-commands`에 없는 명령어. `/spawn`, `/home` 등으로 빠져나갈 수 없습니다.
- 다른 월드로의 텔레포트, 포털 이동
- 블록 부수기와 설치, 양동이, 폭발이나 몹에 의한 지형 변경, 파티원 공격(PvP)

`dungeon.admin` 권한이 있으면 던전 안에서도 명령어 제한을 받지 않습니다. 단, 입장한 상태에서는 관리자도 사망, 텔레포트, 블록 규칙이 똑같이 적용됩니다.

## 명령어

`/던전`과 `/dungeon`은 같은 명령어입니다.

### 플레이어

| 명령어 | 설명 |
|---|---|
| `/던전 입장 <던전>` | 입장 (파티가 있으면 파티장만) |
| `/던전 파티 초대 <플레이어>` | 파티 초대 (60초 유효, 없으면 파티 생성) |
| `/던전 파티 수락` / `거절` | 초대에 답하기 |
| `/던전 파티 나가기` | 파티 나가기 (파티장이 나가면 다음 사람이 이어받음) |
| `/던전 파티 추방 <플레이어>` | 파티원 내보내기 (파티장) |
| `/던전 파티 목록` | 파티원 보기 |

### 관리자

| 명령어 | 설명 |
|---|---|
| `/던전 입장 <던전> <플레이어>` | 대상 입장 (NPC, 콘솔용) |
| `/던전 방 저장 <이름> <시작\|일반\|보스> [테마]` | WorldEdit 선택 영역을 방으로 저장 |
| `/던전 방 삭제 <이름>` / `방 목록` | 방 삭제, 목록 |
| `/던전 생성 <던전> [테마]` / `삭제 <던전>` | 던전 만들기, 지우기 |
| `/던전 정보 [던전]` | 설정과 입장 가능 여부 |
| `/던전 층수 <던전> <층수>` | 층 수 |
| `/던전 방수 <던전> <층> <수>` | 그 층의 일반 방 수 |
| `/던전 보스 <던전> <층> <몹>` | 그 층의 보스 |
| `/던전 몹 <던전> <층> 추가 <몹> [가중치]` | 일반 몹 추가 |
| `/던전 몹 <던전> <층> 제거 <몹>` | 일반 몹 제거 |
| `/던전 보상 <던전> <층> 추가 <확률%>` | 손에 든 아이템을 보상으로 등록 |
| `/던전 보상 <던전> <층> 비우기` | 그 층의 보상 비우기 |
| `/던전 현황` | 진행 중인 던전 |
| `/던전 배치 <번호>` | 현재 층의 방 배치 확인 |
| `/던전 종료 <번호>` | 던전 강제 종료 (아이템을 잃지 않음) |
| `/던전 리로드` | 설정 다시 불러오기 |

몹 이름은 기본 몹이면 `ZOMBIE`, 미믹몹이면 `mythic:이름` 입니다. 탭 자동완성을 지원합니다.

**테마**는 던전마다 다른 방을 쓰기 위한 묶음입니다. 던전은 자기 테마의 방만 사용합니다. 생략하면 `기본`입니다.

### 권한

| 권한 | 설명 | 기본값 |
|---|---|---|
| `dungeon.enter` | 직접 입장 명령어 사용 | 모두 |
| `dungeon.party` | 파티 명령어 사용 | 모두 |
| `dungeon.admin` | 관리 명령어, 던전 안 명령어 제한 무시 | OP |

## 설정

### `config.yml`

| 항목 | 설명 | 기본값 |
|---|---|---|
| `world-name` | 던전 전용 월드 이름. 켤 때마다 지워지므로 기존 월드 이름을 쓰면 안 됨 | `dungeon_instances` |
| `reconnect-seconds` | 접속이 끊긴 뒤 돌아올 수 있는 시간(초) | 300 |
| `entry-delay-seconds` | 맵 준비 후 입장까지 기다리는 시간(초) | 5 |
| `descend-delay-seconds` | 다음 층 발판을 밟은 뒤 내려갈 때까지의 시간(초) | 10 |
| `max-party-size` | 파티 최대 인원 | 4 |
| `allow-player-enter-command` | 플레이어가 직접 입장 명령어를 쓸 수 있는지 | `true` |
| `door-seal-block` | 연결되지 않은 문을 막는 블록 | `STONE_BRICKS` |
| `next-gate-block` | 다음 층 발판 아래에 깔리는 블록 | `CRYING_OBSIDIAN` |
| `exit-gate-block` | 나가기 발판 아래에 깔리는 블록 | `GOLD_BLOCK` |
| `allowed-commands` | 던전 안에서 쓸 수 있는 명령어 | `dungeon`, `던전`, `msg`, `tell`, `w`, `r` |

### 파일

| 파일 | 내용 |
|---|---|
| `dungeons.yml` | 던전, 층, 몹, 보상. 고친 뒤 `/던전 리로드` |
| `rooms.yml`, `rooms/*.schem` | 저장된 방 |
| `sessions.yml` | 던전에 들어간 사람의 복귀 정보. 직접 고치지 마세요 |

## 알아 둘 점

- 층을 지을 때 방을 틱마다 하나씩 붙여 넣습니다. 큰 방을 많이 쓰면 그 순간 서버가 잠깐 느려질 수 있습니다.
- 지나간 층의 건물은 서버를 재시작할 때까지 월드에 남습니다. 오래 켜 두면 `dungeon_instances` 폴더가 커지지만, 재시작하면 지워집니다.
- 보스는 스킬이나 디스폰으로 죽지 않고 사라지면 다시 소환됩니다. 어떤 이유로든 보스가 죽으면 잡은 것으로 칩니다.
- 파티는 메모리에만 있어서 서버를 재시작하면 사라집니다. 던전 밖에서 접속을 끊어도 파티에서 빠집니다.
- 진행 중인 던전에는 `/던전 리로드`로 바꾼 설정 중 일부만 반영됩니다. 새 설정은 다음 입장부터 쓰세요.

## 빌드

JDK 21 이상이 필요합니다. `build.bat`은 저장소가 아래 위치에 있고, Paper 1.21.1을 한 번 실행해 `libraries` 폴더가 만들어진 서버를 기준으로 컴파일합니다. MythicMobs jar는 이 서버의 `plugins` 폴더에서, WorldEdit jar는 `libs` 폴더에서 가져옵니다. `libs`는 저장소에 포함되지 않으므로 `worldedit-bukkit-7.3.9.jar`를 직접 넣어야 합니다.

```
서버/
├─ 1.20.1/                 Paper 서버 (libraries, plugins 사용)
└─ 플러그인/Dungeon/        이 프로젝트
   └─ libs/worldedit-bukkit-7.3.9.jar
```

```bat
build.bat
```

결과물은 `build/Dungeon-Plugin.jar`입니다.
