# Dungeon

입장할 때마다 맵이 달라지는 층별 보스 던전 Paper 1.21.1 플러그인입니다.

- 직접 지은 방을 입장할 때마다 랜덤으로 회전하고 연결해 맵을 조립
- 파티마다 자기만의 던전이 따로 생성 (솔로도 가능)
- 층 보스를 잡아야만 아래층으로 내려가거나 나갈 수 있음
- 던전에서 죽으면 아이템을 모두 잃음 (귀속 저주가 붙은 아이템은 유지)
- 층마다 나오는 몹, 보스, 보상을 직접 지정 (기본 몹, MythicMobs 모두 가능)
- 이벤트 방: 보물 상자(미믹 포함), 축복 제단, 도박 제단, 몹 웨이브
- 던전 안에서만 쓰는 재화와 상점 방 (나가면 재화와 구매품이 사라짐)
- 입장권 아이템과 파티 인원에 따른 몹 마릿수 보정

> **테스트 상태:** 복사본 서버에서 봇 2개로 방 저장, 맵 조립과 회전, 파티 입장, 몹과 보스 소환, 사망과 관전, 보상 상자, 층 이동, 재접속, 시간 초과, 클리어, 서버 정상 종료와 강제 종료 복구까지 확인했습니다. 이벤트 방, 재화, 상점은 봇 1개로 보물과 미믹, 제단, 도박, 웨이브, 구매, 퇴장 시 초기화, 구매품을 상자에 넣지 못하는 동작을 확인했습니다. 입장권과 파티 보정은 봇 2개로 확인했습니다. 사람이 직접 접속한 플레이, **MythicMobs 몹과 보스**, Citizens 같은 NPC 플러그인 연결, 직접 지은 복잡한 방, 여러 파티 동시 진행, 파티로 하는 이벤트 방과 재화 지급, 엔더 상자에 넣은 구매품 삭제, 운영 서버 설치는 아직 시험하지 않았습니다.

## 설치

1. `Dungeon-Plugin.jar`를 서버의 `plugins` 폴더에 넣습니다.
2. 서버를 재시작합니다.

**WorldEdit이 꼭 필요합니다.** MythicMobs는 미믹몹을 쓸 때만 필요합니다.

> 던전 전용 월드 `dungeon_instances`는 **서버를 켤 때마다 지우고 새로 만듭니다.** 이 이름의 폴더에 다른 것을 두지 마세요. 이름은 `config.yml`의 `world-name`에서 바꿀 수 있습니다.

## 빠른 시작

### 1. 방 짓기

방을 만드는 자세한 방법은 [방 설정 가이드](ROOMS.md)에 있습니다.

시작 방, 일반 방, 보스 방은 각각 하나 이상 필요하고, 이벤트 방과 상점 방은 선택입니다. 아무 월드에 방을 지은 뒤 **표지판으로 위치를 표시**합니다. 표지판의 첫 줄(앞면)만 읽으며, 던전에서는 표지판이 지워집니다. `/던전 표지판`을 입력하면 문구가 적힌 표지판을 종류별로 받을 수 있습니다 (OP만 문구가 적용됨).

| 첫 줄 | 의미 | 필요한 방 |
|---|---|---|
| `[문]` | 다른 방과 연결되는 문의 바닥 가운데 칸 | 모든 방 (1개 이상) |
| `[시작]` | 플레이어가 나타나는 곳 | 시작 방 |
| `[몹]` | 일반 몹이 나오는 곳. 표지판 1개에 1마리 | 선택 |
| `[보스]` | 보스가 나오는 곳 | 보스 방 |
| `[보상]` | 보스를 잡으면 상자가 생기는 곳 | 보스 방 |
| `[다음층]` | 다음 층 발판 | 보스 방 |
| `[나가기]` | 출구 발판 | 보스 방 |
| `[보물]` | 보물 상자 | 이벤트 방 (넷 중 하나 이상) |
| `[제단]` | 축복 제단 | 이벤트 방 (넷 중 하나 이상) |
| `[도박]` | 도박 제단 | 이벤트 방 (넷 중 하나 이상) |
| `[웨이브]` | 웨이브 방 표시. `[몹]` 표지판 필요 | 이벤트 방 (넷 중 하나 이상) |
| `[상인]` | 상인이 서 있는 곳 | 상점 방 |

**문 규칙**

- 저장할 영역의 **바깥 벽면**에 두어야 합니다. 모서리에 닿으면 안 됩니다.
- 기본 크기는 너비 3, 높이 3입니다. 다른 크기는 둘째 줄에 `5x4`처럼 `너비x높이`로 적습니다. 너비는 홀수만 됩니다.
- 벽에 문 크기만큼 구멍을 뚫어 두세요. 크기가 같은 문끼리만 연결되고, 연결되지 않은 문은 자동으로 막힙니다.
- 일반 방에는 문이 **2개 이상** 있어야 다음 방으로 이어질 수 있습니다.

### 2. 방 저장

WorldEdit으로 방 전체를 선택하고 저장합니다.

```
//pos1
//pos2
/던전 방 저장 <이름> <시작|일반|보스|이벤트|상점> [테마]
```

표시가 빠졌거나 문 위치가 잘못되면 이유를 알려 주고 저장하지 않습니다. 저장한 방은 `plugins/Dungeon/rooms/`에 들어갑니다.

### 3. 던전 만들기

```
/던전 생성 유적
/던전 층수 유적 3
/던전 방수 유적 1 5
/던전 보스 유적 1 mythic:SkeletonKing
/던전 몹 유적 1 추가 ZOMBIE 3
/던전 몹 유적 1 추가 mythic:Goblin 1
/던전 보상 유적 1 추가 50
/던전 이벤트방 유적 1 2
/던전 상점방 유적 1 50
/던전 보물 유적 1 추가 30
/던전 상점 유적 1 추가 40
/던전 입장권 유적 설정
/던전 정보 유적
```

- `방수`는 시작 방과 보스 방을 뺀 일반 방의 수입니다.
- 몹 뒤의 숫자는 가중치입니다. 위 예시면 `[몹]` 표지판마다 좀비가 3/4, 고블린이 1/4 확률로 나옵니다.
- `보상 추가`는 **손에 든 아이템**을 그 확률(%)로 등록합니다. 이름이나 인챈트가 붙은 아이템도 그대로 저장됩니다.
- `이벤트방`은 그 층에 붙일 이벤트 방의 수, `상점방`은 상점 방이 나올 확률(%)입니다. 기본값은 둘 다 0이라 설정하지 않으면 나오지 않습니다.
- `입장권 설정`은 **손에 든 아이템과 그 수량**을 한 사람당 입장 비용으로 정합니다. 설정하지 않으면 입장권 없이 들어갑니다.
- `보물 추가`는 손에 든 아이템을 보물 상자에서 나올 아이템으로 그 확률(%)로, `상점 추가`는 손에 든 아이템을 그 가격으로 등록합니다.
- `정보`에 `입장 가능`이 나오면 준비가 끝난 것입니다. 부족한 것이 있으면 그 내용이 대신 나옵니다.

### 4. NPC에 연결

콘솔 권한으로 아래 명령어를 실행하게 하면 어떤 NPC 플러그인이든 연결할 수 있습니다.

```
/던전 입장 <던전> <플레이어>
```

Citizens 예시입니다.

```
/npc command add dungeon enter 유적 <p>
```

NPC로만 들어오게 하려면 `config.yml`에서 `allow-player-enter-command: false`로 설정합니다.

## 던전 규칙

### 입장과 진행

- 파티가 있으면 파티장이 입장해야 하고, 접속 중인 파티원이 함께 들어갑니다.
- 맵이 준비되면 5초 뒤 입장합니다. 빠지려면 그 사이에 `/던전 파티 나가기`를 입력합니다.
- 입장권을 설정한 던전은 **입장하는 사람이 각자** 입장권을 냅니다. 파티원 중 한 명이라도 모자라면 입장이 거부되고, 아무도 소모하지 않습니다.
- 입장권은 들어가는 순간에 소모되고 돌려받지 못합니다. 대기 중에 입장권을 잃은 파티원은 그 사람만 제외됩니다. 파티장이 잃으면 입장이 취소됩니다.
- 입장권은 이름과 인챈트까지 같은 아이템만 인정합니다. 입장권을 어떻게 얻을지는 상점, 보상, NPC 등으로 직접 정합니다.
- 입장하면 서바이벌 모드가 되고, 나올 때 원래 게임 모드와 원래 자리로 돌아갑니다.
- 일반 몹과 보스는 플레이어가 그 방에 처음 들어갈 때 나옵니다. 몹은 리젠되지 않습니다.
- 일반 몹을 다 잡지 않아도 보스 방에 갈 수 있습니다.

### 파티 보정

파티 인원이 많을수록 일반 몹과 웨이브 몹이 더 많이 나옵니다. 몹이 나타나는 순간 살아 있는 파티원 수를 기준으로 계산합니다. 접속이 끊겼어도 복귀 시간 안이면 인원에 포함되고, 혼자면 적용되지 않습니다. 기본값 기준 예시입니다.

| 살아 있는 인원 | `[몹]` 표지판 하나의 마릿수 |
|---|---|
| 1명 | 1마리 |
| 2명 | 1~2마리 (평균 1.5) |
| 3명 | 2마리 |
| 4명 | 2~3마리 (평균 2.5) |

- 보스와 미믹은 인원과 관계없이 같습니다. 몹의 체력도 바뀌지 않습니다.

### 보스를 잡으면

- 보상 상자와 `나가기` 발판, `다음 층` 발판이 생깁니다. 마지막 층에는 다음 층 발판이 없습니다.
- `나가기`를 밟으면 그 사람만 아이템을 가지고 나갑니다.
- 누군가 `다음 층`을 밟으면 10초 뒤 남은 파티원이 모두 내려갑니다. 그 사이에 나가기를 밟으면 빠질 수 있습니다.
- 상자는 각자 따로 열립니다. 보스가 죽을 때 살아 있던 사람만 받을 수 있고, **층을 떠나면 꺼내지 않은 보상은 사라집니다.**

### 던전 재화

- 일반 몹, 웨이브 몹, 보스, 보물 상자, 미믹, 웨이브 클리어로 얻습니다. 양은 `config.yml`에서 정하고, 깊은 층일수록 많아집니다.
- 개인 지갑입니다. 누가 잡든 **살아 있는 파티원이 각자 같은 양**을 받습니다. 관전 중에는 받지 못합니다.
- `/던전 지갑`으로 확인합니다. **던전을 나가면 사라지고**, 다음 입장은 0부터 시작합니다.

### 이벤트 방

이벤트 방과 상점 방은 맵의 남은 문에 **막다른 방으로만** 붙습니다. 보스까지 가는 길에 끼지 않으므로 들어가지 않아도 진행할 수 있습니다. 붙일 자리가 없으면 그 층은 이벤트 방과 상점 방 없이 만들어집니다.

| 이벤트 | 동작 |
|---|---|
| 보물 상자 | 처음 열 때 재화를 전원에게 줍니다. 등록한 아이템은 각자 따로 나옵니다. 25% 확률로 미믹이 나오며, 이때는 상자가 사라지고 미믹을 잡아야 재화를 받습니다 |
| 축복 제단 | 누르면 80% 확률로 좋은 효과, 20% 확률로 나쁜 효과를 받습니다. 제단 하나당 1인 1회입니다 |
| 도박 제단 | 재화 20을 걸고 45% 확률로 두 배를 돌려받습니다. 제단 하나당 1인 3회입니다 |
| 몹 웨이브 | 방 안쪽으로 들어오면 문이 닫히고 몹이 3차례 나옵니다. 모두 잡으면 문이 열리고 재화를 줍니다 |

- 웨이브 중에는 밖에 있던 파티원이 들어올 수 없습니다.
- 웨이브 방에 살아 있는 사람이 없어지면 문이 열리고 남은 웨이브 몹이 사라집니다. 그 웨이브 방은 다시 시작되지 않습니다.
- 보물 상자에서 나온 아이템은 일반 아이템이라 가지고 나갈 수 있습니다.

### 상점

- 상점 방의 상인을 우클릭하면 구매 창이 열립니다. 상인은 층의 상품 목록에서 최대 9개를 랜덤으로 골라 팝니다.
- **구매한 아이템은 던전을 나가면 사라집니다.** 인벤토리, 커서, 엔더 상자에서 지워집니다.
- 구매한 아이템은 상자나 셜커 상자 같은 다른 저장 공간에 넣을 수 없습니다. 바닥에 버려 파티원에게 건네줄 수는 있습니다.
- 재고 제한은 없고, 재화가 있는 만큼 살 수 있습니다.

### 죽었을 때

- 인벤토리와 갑옷, 왼손의 아이템 중 **귀속 저주가 없는 것은 모두 삭제**됩니다. 바닥에 떨어지지 않습니다.
- 레벨과 경험치, 엔더 상자의 아이템은 유지됩니다.
- 귀속 저주는 아이템 자체에 붙어 있어야 합니다. 귀속 저주 인챈트북이나 귀속 저주 아이템이 든 셜커 상자는 보호되지 않습니다.
- 죽은 사람은 관전 모드로 남아 다음 층까지 따라다니고, 보상은 받지 못합니다.
- 전원이 죽으면 던전이 끝나고 모두 원래 자리로 돌아갑니다.

### 접속이 끊겼을 때

- 5분 안에 돌아오면 이어서 합니다. 그 사이 파티가 내려갔으면 현재 층의 시작 지점으로 갑니다.
- 5분을 넘기면 사망 처리되어, 다음 접속 때 아이템을 잃고 원래 자리로 돌아갑니다.
- 서버가 재시작되거나 꺼지면 **아이템을 잃지 않고** 원래 자리로 돌아갑니다. 진행 중이던 던전은 사라집니다.
- 서버가 크래시로 죽으면 다음 접속 때 원래 자리로 돌아갑니다. 인벤토리는 마인크래프트 기본 동작대로 마지막 저장 시점으로 되돌아갑니다.
- 접속이 끊긴 채 복귀 시간을 넘긴 뒤에 서버가 꺼져도 사망 처리는 그대로 유지됩니다.

### 던전 안에서 막히는 것

- `allowed-commands`에 없는 명령어. `/spawn`, `/home` 등으로 빠져나갈 수 없습니다.
- 다른 월드로의 텔레포트, 포털 이동
- 블록 부수기와 설치, 양동이, 폭발이나 몹에 의한 지형 변경, 파티원 공격(PvP)

`dungeon.admin` 권한이 있으면 던전 안에서도 명령어 제한을 받지 않습니다. 단, 입장한 상태에서는 관리자도 사망, 텔레포트, 블록 규칙이 똑같이 적용됩니다.

## 명령어

`/던전`과 `/dungeon`은 같은 명령어입니다.

### 플레이어

| 명령어 | 설명 |
|---|---|
| `/던전 입장 <던전>` | 입장 (파티가 있으면 파티장만) |
| `/던전 파티 초대 <플레이어>` | 파티 초대 (60초 유효, 없으면 파티 생성) |
| `/던전 파티 수락` / `거절` | 초대에 답하기 |
| `/던전 파티 나가기` | 파티 나가기 (파티장이 나가면 다음 사람이 이어받음) |
| `/던전 파티 추방 <플레이어>` | 파티원 내보내기 (파티장) |
| `/던전 파티 목록` | 파티원 보기 |
| `/던전 지갑` | 던전 안에서 보유 재화 확인 |

### 관리자

| 명령어 | 설명 |

| `/던전 층테마 <던전> <층> <테마\|해제>` | 그 층에서 쓸 방의 테마 (해제하면 던전 테마) |
| `/던전 보스 <던전> <층> <몹>` | 그 층의 보스 |

| `/던전 입장권 <던전> 설정` | 손에 든 아이템과 수량을 입장권으로 지정 |
| `/던전 입장권 <던전> 해제` | 입장권 없이 입장하게 함 |
| `/던전 이벤트방 <던전> <층> <수>` | 그 층의 이벤트 방 수 |

| `/던전 보물 <던전> <층> 추가 <확률%>` | 손에 든 아이템을 보물로 등록 |
| `/던전 보물 <던전> <층> 비우기` | 그 층의 보물 비우기 |

| `/던전 상점 <던전> <층> 비우기` / `목록` | 그 층의 상품 비우기, 보기 |
| `/던전 현황` | 진행 중인 던전 |

몹 이름은 기본 몹이면 `ZOMBIE`, 미믹몹이면 `mythic:이름` 입니다. 탭 자동완성을 지원합니다.

**테마**는 던전이나 층마다 다른 방을 쓰기 위한 묶음입니다. 각 층은 층 테마의 방만 쓰고, 층 테마가 없으면 던전 테마의 방을 씁니다. 생략하면 `기본`입니다.

## 설정

### `config.yml`

| 항목 | 설명 | 기본값 |
|---|---|---|
| `world-name` | 던전 전용 월드 이름. 켤 때마다 지워지므로 기존 월드 이름을 쓰면 안 됨 | `dungeon_instances` |
| `reconnect-seconds` | 접속이 끊긴 뒤 돌아올 수 있는 시간(초) | 300 |
| `entry-delay-seconds` | 맵 준비 후 입장까지 기다리는 시간(초) | 5 |
| `descend-delay-seconds` | 다음 층 발판을 밟은 뒤 내려갈 때까지의 시간(초) | 10 |
| `max-party-size` | 파티 최대 인원 | 4 |
| `allow-player-enter-command` | 플레이어가 직접 입장 명령어를 쓸 수 있는지 | `true` |
| `door-seal-block` | 연결되지 않은 문을 막는 블록 | `STONE_BRICKS` |
| `next-gate-block` | 다음 층 발판 아래에 깔리는 블록 | `CRYING_OBSIDIAN` |
| `exit-gate-block` | 나가기 발판 아래에 깔리는 블록 | `GOLD_BLOCK` |
| `allowed-commands` | 던전 안에서 쓸 수 있는 명령어 | `dungeon`, `던전`, `msg`, `tell`, `w`, `r` |
| `party-scaling.mob-count-percent` | 파티원이 1명 늘 때마다 더해지는 일반 몹 수 비율(%). 0이면 끔 | 50 |
| `currency-name` | 재화 이름 | `던전 코인` |
| `coins.mob` / `boss` / `treasure` / `mimic` / `wave-clear` | 재화 지급량 | 5 / 50 / 30 / 60 / 40 |
| `coins.floor-bonus-percent` | 층이 깊어질 때마다 늘어나는 비율(%) | 50 |
| `treasure.mimic-chance` / `mimic-mob` | 미믹 확률(%)과 몹 (`mythic:이름` 가능) | 25 / `ZOMBIE` |
| `altar.block` | 축복 제단 블록 | `ENCHANTING_TABLE` |
| `altar.curse-chance` | 나쁜 효과가 나올 확률(%) | 20 |
| `altar.blessings` / `curses` | 효과 목록. 한 줄에 `효과이름 레벨 초` | `config.yml` 참고 |
| `gamble.block` / `bet` / `win-chance` / `max-uses` | 도박 블록, 판돈, 성공 확률(%), 제단당 1인 횟수 | `LODESTONE` / 20 / 45 / 3 |
| `wave.count` / `door-block` | 웨이브 수, 문을 막는 블록 | 3 / `IRON_BARS` |
| `shop.slots` | 상인 한 명이 파는 상품 수 (최대 27) | 9 |

기존 서버를 업데이트할 때 `config.yml`은 자동으로 바뀌지 않습니다. 이벤트 설정을 바꾸려면 위 항목을 직접 추가하세요. 없는 항목은 위 기본값으로 동작하지만, 제단 효과 목록(`altar.blessings`, `curses`)은 추가해야 제단이 작동합니다.

## 알아 둘 점

- 층을 지을 때 방을 틱마다 하나씩 붙여 넣습니다. 큰 방을 많이 쓰면 그 순간 서버가 잠깐 느려질 수 있습니다.
- 지나간 층의 건물은 서버를 재시작할 때까지 월드에 남습니다. 오래 켜 두면 `dungeon_instances` 폴더가 커지지만, 재시작하면 지워집니다.
- 보스는 스킬이나 디스폰으로 죽지 않고 사라지면 다시 소환됩니다. 어떤 이유로든 보스가 죽으면 잡은 것으로 칩니다.
- 파티는 메모리에만 있어서 서버를 재시작하면 사라집니다. 던전 밖에서 접속을 끊어도 파티에서 빠집니다.
- 진행 중인 던전에는 `/던전 리로드`로 바꾼 설정 중 일부만 반영됩니다. 새 설정은 다음 입장부터 쓰세요.

## 빌드

JDK 21 이상이 필요합니다. `build.bat`은 저장소가 아래 위치에 있고, Paper 1.21.1을 한 번 실행해 `libraries` 폴더가 만들어진 서버를 기준으로 컴파일합니다. MythicMobs jar는 이 서버의 `plugins` 폴더에서, WorldEdit jar는 `libs` 폴더에서 가져옵니다. `libs`는 저장소에 포함되지 않으므로 `worldedit-bukkit-7.3.9.jar`를 직접 넣어야 합니다.

```
서버/
├─ 1.20.1/                 Paper 서버 (libraries, plugins 사용)
└─ 플러그인/Dungeon/        이 프로젝트
   └─ libs/worldedit-bukkit-7.3.9.jar
```

```bat
build.bat
```

결과물은 `build/Dungeon-Plugin.jar`입니다.
